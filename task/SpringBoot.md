| Yếu tố                                                          | Tỷ trọng | Lý do                                                                             |
|-----------------------------------------------------------------| -------- |-----------------------------------------------------------------------------------|
| **Dependency Injection (IoC, @Component/@Service/@Repository)** | **20%**  | Nền tảng của mọi thứ trong Spring. Hiểu đúng → code gọn, test được, mở rộng được. |
| **Spring MVC (Controller, RequestMapping, DTO)**                | **18%**  | 90% công việc backend fresher là CRUD + REST API.                                 |
| **Spring Data JPA (Repository, Hàm Query)**                     | **15%**  | Viết DB nhanh, đúng chuẩn, giảm SQL tay.                                          |
| **Configuration & application.yml**                             | **10%**  | Quyết định app chạy thế nào ở dev/prod. Sai là toang ngay.                        |
| **Exception Handling (@ControllerAdvice)**                      | **7%**   | Phân biệt code nghiệp dư vs code công ty.                                         |
| **Validation (Bean Validation)**                                | **5%**   | API sạch, giảm bug runtime, cực rẻ công học.                                      |
